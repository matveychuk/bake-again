# Bake Again Design System v1

**Direction:** Warm Precision / Review applied  
**Foundation status:** Approved  
**Established:** 2026-09-07

This system translates the approved Bake Again homepage into reusable rules for web and
future mobile interfaces. It is intentionally small: product patterns are added when a
real screen needs them.

## Sources of truth

1. `tokens.json` contains portable design decisions for Figma and other platforms.
2. `tokens.css` contains the semantic variables used by the web product.
3. The components used in `/design-system` demonstrate the expected implementation.
4. These documents define meaning, content and accessibility.
5. `AGENTS.md` tells Codex how to apply the system.

When sources disagree, preserve the approved product meaning first, then update tokens,
code and documentation together. A Figma frame is a design reference, not generated
production CSS.

## Files

- `foundations.md` — colour, typography, spacing, shape, imagery and responsive rules.
- `components.md` — current base component contracts.
- `patterns.md` — product-level composition rules.
- `status-provenance.md` — evidence states and required language.
- `accessibility-localisation.md` — inclusive and multilingual requirements.
- `instagram-reels.uk.md` — approved social video layout and reusable horizontal stamp.
- `pdf-recipes.uk.md` — reusable mobile recipe PDF rules, linked data/layout package,
  typography, image fidelity and delivery verification.
- `tokens.json` — portable semantic tokens.
- `tokens.css` — web token implementation.
- `CHANGELOG.md` — approved system changes.

## Design principles

- Practical before editorial.
- Food first.
- Warmth through colour, photography and materiality.
- Precision through structure, copy and provenance.
- Quality before catalogue volume.
- Clear uncertainty rather than false confidence.
