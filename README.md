# Bake Again

Working repository for a multilingual gluten-free baking product built around a small collection of repeatedly tested home recipes.

`Bake Again` is the current working product name. It may be changed after the dedicated naming review without changing the recipe IDs or content architecture.

## Repository structure

```text
content/recipes/       Structured multilingual recipe content
docs/content-model/    Recipe schema decisions and authoring workflow
docs/reference/        Project briefs, research and recipe inventory
media/recipes/         Original and selected recipe media
```

The repository also contains the current Next.js website prototype and its existing Git history.

## Current state

- Recipe content model drafted.
- Crinkle Cookies and Gluten-Free Napoleon populated as multilingual drafts.
- Missing content remains explicit in each recipe's `contentGaps`.
- Existing website prototype preserved as the implementation starting point.
- No CMS or database is required for the initial collection.
