### DNS — як домен підключено

DNS обслуговує **Spaceship**, nameservers:

- `launch1.spaceship.net`
- `launch2.spaceship.net`

Наведені нижче чотири записи збережені 25.09.2026. TTL — **30 min**.
У полі Host Spaceship сам додає `.bakeagain.com`: вводимо тільки значення з таблиці.

| Тип | Host | Значення |
| --- | --- | --- |
| A | `@` | `162.159.143.30` |
| A | `@` | `172.66.3.26` |
| TXT | `_openai-site-verification` | `openai-site-verification=cnlcKc2rhJXm6Es73wcPtoFCruq5lylMZVLQhGH4oks` |
| TXT | `_cf-custom-hostname` | `8e11cc89-ec13-43fb-999d-3e7ffd1d21d5` |

Обидва A-записи потрібні: саме ці адреси надав Sites. Spaceship показував
попередження про конфлікт через однаковий Host; після підтвердження підключення
успішно активувалося. TXT-значення — публічні DNS-підтвердження, не паролі.
Після активації Sites повертав лише перший TXT у списку вимог, але другий
залишений у DNS. Не видаляти записи без перевірки актуальних вимог Sites.

`www.bakeagain.com` окремо **не підключали**. Підтверджена адреса — без `www`.

| Оплата | Платну послугу під час підключення не замовляли; тариф і білінг акаунта окремо не перевірені |

Значення ключів у цей довідник і Git не записуємо. Керувати ключами можна в
налаштуваннях віджета Cloudflare; робочі значення для сайту збережені в Sites.
Тимчасовий файл перенесення ключів видалений після підключення.

Turnstile перевіряє відвідувача перед власним запитанням до AI. Готові запитання
та відповіді працюють без виклику AI й без цієї перевірки. Ліміти запитів і витрат
забезпечує сервер сайту з базою `ASSISTANT_QUOTAS` у Sites, а не сам віджет.
Без успішної перевірки захищений запит до AI не виконується.

DNS залишається у Spaceship, хостинг — у Sites. Для підключення Turnstile
переносити домен або хостинг у цей акаунт Cloudflare не знадобилося.

Докладніше: [ліміти та захист AI](assistant-protection.md),
[звіт про підключення Turnstile](assistant-turnstile-activation.md).

## Якщо через рік потрібно щось змінити

| Завдання | Де почати та що перевірити |
| --- | --- |
| Продовжити домен / змінити оплату | Spaceship → Domain Manager → bakeagain.com; перевірити дату та Auto-renew, потім спосіб оплати в акаунті |
| Змінити контактний email | Spaceship → Domain Contacts; окремо перевірити email самого акаунта та відновлення доступу |
| Перенести сайт на інший хостинг | Спочатку підготувати сайт на новому хостингу; отримати його DNS-записи, тоді змінити записи в Spaceship та перевірити HTTPS |
| Додати адресу з www | Спочатку додати `www.bakeagain.com` у Sites, отримати актуальні DNS-вимоги та визначити основну адресу / перенаправлення |
| Змінити домен сайту | Узгодити Sites, DNS, Umami, `analyticsConfig.hostname`, SEO-адреси, редиректи та `PRODUCTION_URL`; оновити дозволений hostname віджета Turnstile й `ASSISTANT_ALLOWED_HOSTNAME` у Sites |
| Замінити ключі Turnstile | Cloudflare → Turnstile → Bake Again AI assistant; зберегти актуальні ключі в налаштуваннях Sites, повторно розгорнути сайт і перевірити власне запитання до AI |
| Turnstile не пропускає запит | Перевірити дозволений hostname, стан віджета та ключі в Sites; звіритися з інструкцією захисту AI. Готові відповіді залишаються доступними |
| Подивитися статистику | Umami → Bake Again → потрібний діапазон дат → Pages / Referrers / Events |
| Статистика не надходить | Перевірити hostname, опубліковану версію, завантаження скрипта, Do Not Track / блокувальник і появу реального перегляду в Umami |
| Відкрити сайт для всіх | Перевірити готовність опублікованої версії, змінити аудиторію в Sites та перевірити відкриття без авторизації |
