# Новые доказательства аудита eed65f7

Все материалы созданы 27.09.2026 для `../pre-publication-audit.md`. Исторические evidence не использованы как результат текущего прохода.

Origin браузерных сценариев: `http://localhost:3013`, свежая production-сборка через Wrangler. Chrome 153.0.8010.53, macOS, headless. Каждый сценарий, изменяющий локальные данные, использует новый изолированный context; реальный профиль не подключается. Внешние `external-*.html` получены анонимными GET без cookies и авторизации.

## Основные материалы

- `baseline.json`, `preservation.json` — HEAD, исходное состояние и SHA-256 сохранности существующих файлов.
- `automated-checks.json/.log`, `build.log`, `release-render.log` — свежие команды и результаты.
- `manifest.mjs/.json` — независимый список 27 рецептов × 3 языка из текущего registry.
- `matrix.json` — 450 базовых загрузок, HTTP, lang, H1, alt, overflow, ошибки загрузки.
- `quantities.json` — 54 переключения масштаба, ingredients/method и 648 полных текстов экранов Cook.
- `defect-excerpts.json`, `defects.json`, `d01-*.png`, `r02-*-detail-*.png` — выделенные расхождения.
- `configurations.json` — 153 конфигурации Наполеона, каждая до JS и после загрузки, состояние сохранённых сессий.
- `navigation.json`, `return-debug.json` — неработающие ссылки с JS, контроль без JS, ошибки и stack браузера.
- `invalid-session.json` — неверный scale использует и меняет базовую тестовую сессию.
- `ui-followup.json` — ввод 200 г через UI на 9 сочетаниях; покупки Наполеона с обязательным выбором молочного продукта; checkbox/reload.
- `notes-compositions.json` — 54 сценария R02 и 18 композиций; detail, review, list, reload, localStorage, Cook и завершение.
- `broad-actions.json` — 66 рецептов/компонентов × действия на 2×, сохранение и покупки.
- `media-composition-layout.json` — 109 уникальных декодированных изображений на 22 EN detail, 54 композиционных состояния всех ширин.
- `keyboard.json` — первоначальный клавиатурный сценарий, остановленный подтверждённой ошибкой возврата из Cook.
- `keyboard-continuation.json` — остальные клавиатурные действия на 9 сочетаниях.
- `focus-settled.json` — повторный контроль 18 диалогов × 25 Tab с ожиданием переноса фокуса.
- `compatibility.json` — синтетические legacy ID сохранений, имена кремов в сохранённых покупках, переходы языков/query/fragment, 200% текста.
- `flows.json` — таймер, завершение, заметка/reload, переключение языка. Чтение ссылки немедленно после ввода может фиксировать промежуточное состояние; окончательный результат ввода — `ui-followup.json` после завершения обновления.
- `shopping-management.json` — удаление/undo, удаление купленного, cancel/clear и reload тестовых списков.
- `http-seo.json` — HTTP-рецепты, 162 миграционных запроса, закрытые пути, персональные страницы и внешние ответы.
- `seo-browser.json` — 78 sitemap URL с метаданными из DOM при выключенном JavaScript. Поле `alternates` раннего regex в `http-seo.json` не распознавало другой порядок HTML-атрибутов; вывод о hreflang сделан по DOM в `seo-browser.json`.
- `*.png` — новые контрольные screenshots. Некоторые ранние кадры содержат ещё не загруженные lazy-images; ошибки изображений определялись декодированием, а не пустым placeholder.

## Интерпретация журналов

Успешный сценарий подтверждает только свои assertions. Например, `quantities.log` проверяет прежние контрольные количества масла/сахара/дисков/молока; непересчитанные яйца и сборка выявлены чтением полных текстов и вынесены в `defect-excerpts.json`. `matrix.log` относится к загрузке страниц, не ко всем действиям; ошибка выхода Cook записана отдельно.

Первые попытки с неточным переводом селектора, без ожидания обновления страницы или без обязательного выбора сметаны/йогурта не объявлены дефектами. Окончательные сценарии повторены. Быстрые первичные Tab-проверки захватывали промежуточное перенесение фокуса; контроль с ожиданием записан отдельно. Возврат Cook, наоборот, повторён мышью, Enter, прямым URL и без JS: это подтверждённая ошибка продукта.

`*.cjs/.mjs` — сценарии именно этого аудита, не изменения тестового набора продукта. `browser-common.cjs` использует локальный установленный Playwright; для запуска на другом компьютере потребуется соответствующий путь зависимости. Сценарии не публикуют сайт и не обращаются к платному API. Новый аудит следует выполнять в новых профилях и на новой production-сборке, сохраняя эти результаты как исторические.
